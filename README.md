# Blox Fruits Game - How to Play

## Starting the Game

1. Open `index.html` in a modern web browser (Chrome, Firefox, Edge, Safari)
2. You should see the "PICK A SIDE!" screen with two cards:
   - **PIRATES** (Red card with pirate flag)
   - **MARINES** (Blue card with anchor)

3. Click on either card to start the game

## If the Game Doesn't Load

### Check Browser Console
1. Press F12 to open Developer Tools
2. Click on the "Console" tab
3. Look for any error messages in red

### Common Issues:
- **"THREE is not defined"**: The Three.js library didn't load. Check your internet connection.
- **Blank screen after clicking**: Check console for JavaScript errors
- **Nothing happens when clicking**: Make sure JavaScript is enabled in your browser

### Quick Fix:
If you see errors, try:
1. Hard refresh the page (Ctrl+F5 or Cmd+Shift+R)
2. Clear browser cache
3. Try a different browser

## Controls

### Movement
- **W** - Move forward
- **A** - Move left  
- **S** - Move backward
- **D** - Move right

### Camera
- **Q** - Rotate camera left
- **E** - Rotate camera right
- **Right-click + Drag** - Free camera rotation
- **Scroll** or Zoom buttons - Zoom in/out

### Combat
- **SPACE** or **Left-click** - Melee attack
- **Z** - First fruit move
- **X** - Second fruit move
- **C** - Third fruit move
- **V** - Ultimate fruit move

### Menus
- **M** - Map
- **I** - Inventory
- **B** - Shop
- **T** - Stats
- **ESC** - Close menus

## Game Features

### Starter Island
- 6 colorful buildings with different roof colors
- Wooden dock for boats
- Palm trees around the perimeter
- Central grass plaza
- Enemies spawn automatically

### Combat System
- Fight enemies to gain EXP and money
- Level up to unlock new islands
- Each fruit has 4 moves with different mastery requirements
- Damage numbers appear when hitting enemies

### Fruit System
- Buy fruits from the shop (B key)
- Each fruit has unique abilities
- Gain mastery by using fruit moves
- Higher mastery = more damage

### Quest System
- Accept quests from the quest menu
- Complete objectives to earn rewards
- Track progress in the HUD
